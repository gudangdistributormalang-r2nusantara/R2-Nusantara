# Images placeholder and upload instructions

This directory stores brand and product images used by the UI/UX upgrade.

Please add the asset images (provided in chat) with the following filenames:

- assets/logo/icon-192.png   (recommended: square 192x192)
- assets/logo/icon-512.png   (recommended: square 512x512)
- assets/images/brand/hero.webp  (hero banner optimized WebP)
- assets/images/products/sample-400.webp
- assets/images/products/sample-800.webp
- assets/images/products/sample-1200.webp

If you prefer, you can upload the original PNG/JPG files and run the conversion script in /scripts to generate WebP variants.
